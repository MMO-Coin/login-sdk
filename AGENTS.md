# Repository instructions

- Work directly on main. Do not create, switch to, or use another branch.
- Write short commit titles in English. Leave the commit body empty unless the user asks for details.
- Never add a co-author or assistant attribution to commits.
- Use plain, natural language in public documentation. Avoid exaggerated claims.
- Do not use em dashes in new or edited text. Use a sentence, comma, or bullet instead.
- Preserve key derivation inputs, signed messages, header names, storage keys, database tables, and the shared vault symbol when updating package branding.
- Keep the original MIT copyright notice.
- Run the relevant checks before committing. Do not publish to npm or push changes unless the user requests it.
